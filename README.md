## Instalação

> [!NOTA]
> Até o momento, o **CatOsDotfilles** é compatível e testado apenas para **Arch Linux**.  

> [!WARNING]
> Use o script `install.sh` por sua conta e risco — ele não foi totalmente testado.

```bash
git clone https://github.com/Psyhusk/CatDotsOS.git
cd catdots
./install.sh
```

After install, run:

```bash
catdots init
```
